# AgentHub · 安卓智能体工作台

一款运行在安卓手机上的本地 Agent 应用：**模型全部自定义**（OpenAI 兼容 / Anthropic 双协议），单主智能体自由对话 + 自动派生子智能体协作、画布工作流、媒体生成、定时任务、内置浏览器与 WorkBuddy 绑定，Windows 模拟环境与原生安卓能力，所有数据仅保存在本机。

## 二、安装使用

### 安装 APK

1. 将 `apk/AgentHub-2.4.0-release.apk`（或 `apk/app-debug.apk`）传到手机
2. 点击安装（需允许"安装未知应用"）
3. 打开 → 进入「设置」→ 模型配置 → 点右上角 **+** → 选择平台预设 → 填入密钥 → 完成

> 也可以先在电脑浏览器里体验 Web 版（`web/index.html`），功能与 APK 内基本一致（原生浏览器/SAF 等除外）。

### 添加自定义模型

| 字段 | 示例 |
|---|---|
| 显示名称 | 我的 GPT-4o |
| 模型种类 | 💬 对话（或 🖼️ 图片 / 🎬 视频） |
| 接口类型 | OpenAI 兼容 |
| 调用地址 | `https://api.openai.com/v1`（填到 `/v1` 为止） |
| API 密钥 | `sk-...` |
| 模型名称 | `gpt-4o-mini` |

Anthropic 接口：调用地址填域名即可（如 `https://api.anthropic.com`），自动拼接 `/v1/messages`。

**媒体模型**（图片/视频）额外配置生成能力参数与提交/轮询协议：

| 字段 | 说明 |
|---|---|
| 支持的分辨率 | 逗号分隔，如 `720p, 1080p` |
| 支持的比例 | 逗号分隔，如 `16:9, 9:16, 1:1` |
| 视频最长秒数 | 数字，如 `10` |
| 提交/轮询协议 | `submitPath`、`pollPath`（`{id}` 占位）、`idPath`、`statusPath`、`okStatus`、`resultPath`、轮询间隔——预设已填好常见平台的值 |

### 智能体是怎么协作的

只有一个**主智能体**，你只管自由对话。当任务需要专业能力时，主智能体会**按需自己创造子智能体**（不预分类、不用你手动创建），可一次派多个**并行**干活，结果回喂后由它汇总回复——就像 WorkBuddy 的专家团，但模型全部由你自己配置：

```
你：帮我写一个贪吃蛇，再做一个官网首页
主智能体：[[ACTION:spawn|编程助手|写贪吃蛇存到 /home/agent/workspace/game.py]]
           [[ACTION:spawn|网页设计师|做一个官网首页存到 /home/agent/workspace/index.html]]
  → 🧬 两个子智能体同时被创造，并行执行（各自独立上下文 + 工具白名单）
  → ✅ 结果回喂主智能体
主智能体：都搞定了，文件在 /home/agent/workspace/，点文件即可预览网页。
```

- 子智能体由主智能体动态创造、自动复用；已创造的智能体在「智能体」页可查看与管理
- 最多 40 个子智能体同时运行、累计最多创造 300 个；子智能体还能再创造孙级（最多 2 层）
- 「智能体 → 协作视图」打开思维导图，实时看每个 agent 在干什么、产出什么
- 「智能体 → 实时看板」查看每个 agent 的实时状态（思考中 / 生成中 / 调用工具 / 完成 / 失败）
- 主智能体人设留空时自动使用内置默认提示词（含完整协作协议）；也可在「智能体 → 编辑」中自定义
- 定时任务、画布工作流里的智能体节点同样带完整协作能力

### 安装与使用技能

「智能体 → 技能库」或「应用 → 技能库」：23 个内置技能开箱即用（网页设计、CSS 设计、SVG 插画、3D 建模、游戏开发、编译构建、前端、测试、代码审查、数据分析、数据可视化、文案、新媒体、Prompt、调研、插画、视频导演、数据库、API 设计、架构、安全审计、DevOps、文档），可卸载；也可以**自写技能**——填名称、提示词、勾选可用工具，主智能体遇到匹配任务会自动调用（你也可以直接说「用文案技能写个口号」）。

### 万能预览：什么格式都能看

文件页点击任意文件即进入万能预览器：

| 类型 | 预览方式 |
|---|---|
| 网页 / 界面（html） | iframe 渲染，手机框 / 桌面 / 代码三视图切换 |
| 代码 / Markdown / JSON / CSV | 代码高亮、Markdown 渲染、JSON 美化、CSV 表格 |
| 图片 / 音频 / 视频 | 直接播放（base64/URL 自动识别） |
| 3D 模型（obj/stl） | Three.js 实时渲染：**环境反射（PMREM）+ ACES 色调映射 + 软阴影接触阴影 + 三点布光**，实时切换**陶瓷/金属/玻璃/哑光/线框**五种物理材质，拖动旋转、双指缩放 |
| Three.js 场景（js） | 「运行 3D 场景」一键跑起来 |
| 样式表（css） | 效果预览（样式示例页）/ 代码 / **应用到 HTML**（选一个 HTML 文件注入样式，预览合并效果并可另存） |
| 矢量图（svg） | 渲染（data URI 安全渲染，动画自动播放）/ 代码双视图，script 自动剥离 |

3D 内容让智能体写（「画一个 3D 机器人，保存成 obj」），在「应用 → 3D 工坊」里统一查看。

### 让 Agent 用浏览器搜索

直接在对话里说「帮我搜一下 XX」，主智能体会输出 `[[ACTION:browser.search|XX]]`，应用自动打开内置浏览器搜索并提取结果回喂，最终答案以 AgentHub 自己的 UI 呈现。

### 绑定 WorkBuddy

「应用 → WorkBuddy 绑定 → 打开并开始绑定」→ 输入手机号（应用自动填入页面）→ 应用点击获取验证码 → 你输入验证码 → 应用自动填入并登录 → 之后可一键同步任务实况、调用专家团。

- **请求直连**：API 请求由 WebView 直接发往你配置的地址，不经过任何中转服务器
- **存储**：模型/密钥/会话/工作流/任务均存于 WebView localStorage（应用私有目录）
- **沙箱**：终端 node 执行使用 `new Function` 隔离沙箱；文件系统为虚拟磁盘
- **浏览器自动化**：AutoBus 静态命令总线 + BrowserActivity 内页面脚本注入，SPA 投递命令、轮询结果

## 五、使用技巧

1. **自动分工**：直接说需求，主智能体自己决定要不要派子智能体；对话里的虚线卡片就是子智能体的实时工作过程
2. **多派并行**：一句话里包含多个需求（「写个贪吃蛇，再做个官网」），主智能体会自动并行派工；协作视图里能看到实时分工
3. **自定义人设**：智能体 → 编辑主智能体 → 系统提示词；「填入默认提示词」可恢复内置协作协议
4. **画布工作流**：开始 → 智能体 → 条件 → 图片生成 → 输出，连起来点「运行」即可看到每个节点状态
5. **定时任务**：让主智能体每天早上汇总信息，结果自动存到虚拟磁盘「下载」目录
6. **媒体保存**：生成图片/视频后点「保存」，写入你设置过的本地文件夹（SAF 二进制直存）
7. **自写技能**：技能库 → 新建技能，写好提示词与工具白名单，主智能体即按需调用
8. **编译与运行**：让 Agent「写个程序并编译运行」——JS 会真实执行并回显输出；或对智能体说「编译 /home/agent/workspace 下的所有代码」批量检查
9. **跑 .exe**：在虚拟磁盘放一个 .exe（内容是 JS 脚本或 `{"app":"calc"}` 这样的 JSON 定义），文件页点 ▶ 即可在 Windows 模拟环境中运行
10. **横屏**：v2.4 起默认横屏（宽屏工作台）；环境顶栏点 ⟳ 或设置页切换竖横屏（APK 中真实旋转屏幕），安卓环境自动变双栏、Windows 桌面图标变多列
11. **3D 光感**：预览 OBJ/STL 时可一键切换陶瓷/金属/玻璃/哑光材质；对智能体说「画一个带金属反光的 3D 机器人」，3D 建模师会按电影级布光规范生成场景
12. **液态玻璃**：v2.2 起界面为玻璃拟态（backdrop-filter 模糊 + 半透明 + 高光边），图标全部 SVG/CSS 绘制
13. **深度思考**：默认开启，主智能体回复前会先展示可展开查看的「思考过程」卡片；若思考是英文等其它语言，会自动翻译为中文并标注「已自动翻译」。不想看可在「设置 → 深度思考」关闭，或只关「思考自动翻译为中文」
14. **后台常驻**：默认开启——退出界面任务继续跑，通知栏有常驻提示（点通知回应用、点「停止」结束保活）；不需要可在「设置 → 后台运行」关闭。注意：系统「强制停止」或部分厂商系统的深度清理仍会中断进程，这是 Android 系统策略
15. **真实文件夹**：先在「设置 → 保存位置」选一个手机文件夹，再进 Windows 环境开终端——`ls/cat/node 文件.js` 操作的就是真实文件；终端里输入 `real off` 可随时切回虚拟磁盘
16. **全局搜索**：对话页右上角放大镜，一次搜对话/智能体/模型/技能/文件，点结果直达
17. **CORS 提示**：若某接口报"网络请求失败/跨域"，换用支持浏览器跨域的接口地址即可（多数主流服务商均支持）
